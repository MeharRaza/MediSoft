## 🎯 MOST USED SHORTCUTS

```
┌─────────────────────────────────────────────────────┐
│  Ctrl + S  →  💾 SAVE BILL (Finish Sale)          │
│  Ctrl + H  →  📊 ITEM HISTORY (when in cart)       │
│  Ctrl + F  →  💵 FLAT DISCOUNT (PKR)               │
│  Ctrl + T  →  📉 PERCENT DISCOUNT (%)              │
│  Ctrl + P  →  💳 PAYMENT METHOD (Cash/Credit)      │
└─────────────────────────────────────────────────────┘

## 📋 ALL SHORTCUTS

### Main Actions
| Press This | To Do This |
|-----------|------------|
| **Ctrl + S** | Save bill (finish sale) |
| **F10** | Save bill (alternative) |
| **F8** | Hold bill (save for later) |
| **F1** | Focus search box |

### Navigation
| Press This | To Do This |
|-----------|------------|
| **Ctrl + ←** | Previous held bill |
| **Ctrl + →** | Next held bill |
| **↑ ↓** | Navigate search results |
| **Arrow Keys** | Navigate cart table |

### Quick Input
| Press This | To Do This |
|-----------|------------|
| **Ctrl + T** | Jump to percent discount |
| **Ctrl + F** | Jump to flat discount |
| **Ctrl + P** | Toggle payment method |
| **Ctrl + Shift + A** | Jump to amount received |

### Item Actions
| Press This | To Do This |
|-----------|------------|
| **Ctrl + H** | Show item history (when in cart row) |
| **Enter** | Add product / Next field |
| **Tab** | Next input field |
| **Esc** | Close modal / Clear search |

```

## 📊 ITEM HISTORY (Ctrl + H)

**When to use:**
- Before pricing expensive items
- To check what price was charged before
- To see which customers buy this item
- To maintain consistent pricing

**What it shows:**
- Total sales & quantity
- Average, max, and min prices
- Last 50 sales with dates & customers
- Invoice numbers & cashier names

**How to use:**
1. Add item to cart
2. Press Tab to go to item's field
3. Press **Ctrl + H**
4. Review history
5. Press **Esc** to close

## 💡 TIPS & TRICKS

### Speed Tips
1. ⚡ Use **Ctrl+S** instead of clicking button
2. ⚡ Use **Ctrl+T/F** instead of scrolling
3. ⚡ Use **Tab/Enter** instead of mouse
4. ⚡ Use **↑↓** to navigate search

### Accuracy Tips
1. ✅ Press **Ctrl+H** before pricing unknowns
2. ✅ Check **avg price** in history
3. ✅ Use **Ctrl+F** for flat discounts
4. ✅ Use **Ctrl+T** for percent discounts

### Common Mistakes
1. ❌ Don't use Ctrl+H when not in cart
2. ❌ Don't forget to press Ctrl+S to save
3. ❌ Don't click buttons when shortcuts exist
4. ❌ Don't scroll when Ctrl+T/F available

## 🎯 CART NAVIGATION

```
┌──────────────────────────────────────────────┐
│ Product   │ Qty   │ Price  │ Disc%          │
├──────────────────────────────────────────────┤
│ Panadol   │ [10]  │ 12.50  │ 0              │
│              ↑↓      →←       →←             │
│              Tab     Tab      Tab            │
│              Ctrl+H (history)                │
└──────────────────────────────────────────────┘

↑↓  = Move between rows
→←  = Move between fields  
Tab = Move to next field
Shift+Tab = Move to previous field
Ctrl+H = Show item history
```

## 🚨 TROUBLESHOOTING

### Ctrl+H not working?
- Make sure you're IN a cart row field (Qty/Price/Disc)
- Cart must have at least one item
- Click on field first, then try Ctrl+H

### Ctrl+S doing nothing?
- Cart must have at least one item
- Check if sale is already in progress
- Try F10 instead

### Shortcuts not working at all?
- Refresh page (F5)
- Check if focus is in correct field
- Make sure modal isn't open
