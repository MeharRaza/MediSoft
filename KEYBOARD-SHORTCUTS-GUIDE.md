### **🛒 Fast Billing - Product Search Navigation**

| Shortcut | Action | Description |
|----------|--------|-------------|
| `F1` | Focus Search | Jump to product search box |
| `↓ Down Arrow` | Next Result | Move to next search result |
| `↑ Up Arrow` | Previous Result | Move to previous search result |
| `Enter` | Add to Cart | Add selected product to cart |
| `Esc` | Clear Search | Close search results |

**💡 Auto-select:** First result is automatically highlighted!

---

### **📊 Fast Billing - Cart Table Navigation (EXCEL-LIKE!)**

**Spreadsheet-Style Navigation:**

| Shortcut | Action | Description |
|----------|--------|-------------|
| `→ Right Arrow` | Next Field | Move Qty → Price → Disc% |
| `← Left Arrow` | Previous Field | Move Disc% → Price → Qty |
| `↓ Down Arrow` | Next Row | Move to same field in next item |
| `↑ Up Arrow` | Previous Row | Move to same field in previous item |
| `Enter` | Next Field/Row | Smart navigation forward |
| `Tab` | Next Field | Move to next editable field |
| `Shift + Tab` | Previous Field | Move to previous field |

**💡 Works exactly like Microsoft Excel!**

**Cart Navigation Flow:**
```
Row 1: [Qty] → [Price] → [Disc%]
         ↓        ↓         ↓
Row 2: [Qty] → [Price] → [Disc%]
         ↓        ↓         ↓
Row 3: [Qty] → [Price] → [Disc%]
```

**Features:**
- ✅ Navigate between Quantity, Price, Discount fields
- ✅ Move up/down between multiple cart items
- ✅ Visual focus indicator (blue ring)
- ✅ Enter at last field returns to search
- ✅ No mouse needed for cart editing!

## 🎯 **USE CASES - Real Workflow Examples**

### **Use Case 1: Quick Sale (Fastest Way)**

```
Customer comes to counter:
1. Press F1 (Fast Billing opens)
2. Type medicine name
3. ↓ Arrow key (select from results)
4. Enter (add to cart)
5. → Right arrow (move to price if needed)
6. Type new price (optional)
7. → Right arrow (move to discount)
8. Type discount % (optional)
9. Repeat for more items (search or ↓ to next row)
10. F10 (finalize sale)
11. Print invoice

Time: 20-30 seconds! ⚡
Full keyboard control - Excel-like navigation!
```

### **Use Case 2: Check Stock**

```
Phone call - "Do you have XYZ medicine?"
1. Press F2 (Products page)
2. Type medicine name in search
3. Enter (see details)
4. Check stock quantity
5. F1 (back to billing if needed)

Time: 10 seconds! ⚡
```

### **Use Case 2.5: Multi-Item Cart Editing (NEW!)**

```
Customer wants multiple items with custom prices:
1. Press F1 (Fast Billing)
2. Search & add Item 1 (Enter)
3. Search & add Item 2 (Enter)
4. Search & add Item 3 (Enter)
5. Click Qty field of first item (or Tab to it)
6. Type quantity: 5
7. → Right arrow (move to Price)
8. Type custom price: 150
9. → Right arrow (move to Disc%)
10. Type discount: 10
11. ↓ Down arrow (move to Item 2 Qty)
12. Adjust Item 2 (repeat arrow navigation)
13. ↓ Down arrow (move to Item 3)
14. Adjust Item 3
15. Enter (back to search or F10 to finish)

Time: 45 seconds for 3 items! ⚡
Like Excel spreadsheet - super fast!
```

### **Use Case 3: Record Purchase**

```
Supplier delivery arrived:
1. Press F4 (Purchase Entry)
2. Select supplier (Tab, Arrow keys, Enter)
3. Add items (Tab through fields)
4. Enter quantities & prices
5. Ctrl+Enter (save purchase)

Time: 2 minutes for 10 items! ⚡
```

### **Use Case 4: Daily Reports**

```
End of day reporting:
1. Press Alt+8 (Reports)
2. Select date range (Tab, Arrow keys)
3. Enter (generate report)
4. Review numbers
5. Alt+1 (back to Dashboard)

Time: 1 minute! ⚡
```
