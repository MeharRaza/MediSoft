## ⌨️ Keyboard Shortcuts

### **Product Search (Step 1)**

| Key | Action |
|-----|--------|
| `F1` | Focus product search box |
| Type product name | Search products |
| `↓` Down Arrow | Next search result (auto-selected) |
| `↑` Up Arrow | Previous search result |
| `Enter` | Add selected product to cart |
| `Esc` | Clear search |

**Example:**
```
1. Press F1
2. Type "para" (for Paracetamol)
3. First result automatically selected (blue highlight)
4. Press ↓ to see more options
5. Press Enter to add to cart
```

---

### **Cart Table Navigation (Step 2)**

Jab products cart mein add ho jayein, tab arrow keys se navigate karein:

#### **Horizontal Navigation (Left/Right)**

| Key | Action | Example |
|-----|--------|---------|
| `→` Right Arrow | Next field | Qty → Price → Disc% |
| `←` Left Arrow | Previous field | Disc% → Price → Qty |
| `Tab` | Next field | Same as Right Arrow |
| `Shift+Tab` | Previous field | Same as Left Arrow |

#### **Vertical Navigation (Up/Down)**

| Key | Action | Example |
|-----|--------|---------|
| `↓` Down Arrow | Next row (same field) | Row 1 Qty → Row 2 Qty |
| `↑` Up Arrow | Previous row (same field) | Row 2 Price → Row 1 Price |

#### **Smart Navigation**

| Key | Action |
|-----|--------|
| `Enter` | Next field, or next row if at end of row |
| `Enter` (at last field) | Return to product search |

## 💡 Pro Tips

### **Tip 1: Start with Search, End with Cart**
```
Workflow:
1. Add all items first (F1 → search → Enter → repeat)
2. Then adjust quantities/prices (arrow navigation)
3. Finish sale (F10)

This is faster than adjusting after each item!
```

### **Tip 2: Use Tab for Forward, Arrows for Flexibility**
```
Tab: Quick forward movement (left to right)
Arrows: Full control (all 4 directions)

Choose based on need:
- Simple qty change: Tab is faster
- Complex editing: Arrows give more control
```

### **Tip 3: Visual Focus**
```
Blue ring around field = currently focused
Watch the blue ring to know where you are
No need to track mentally!
```

### **Tip 4: Enter Key Intelligence**
```
Enter does smart navigation:
- In search results: Adds to cart
- In cart fields: Moves to next field
- At last field: Returns to search
- No need to think - just press Enter!
```

### **Tip 5: Escape to Reset**
```
Lost focus? Confused? 
Press Esc to clear search
Press F1 to return to search box
Start fresh!
```
